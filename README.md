## minesweeper game in your terminal

### Try it out
#### clone
```angular2html
git clone https://github.com/samiyonas/minesweeper
cd minesweeper
```

#### run the release build(if you don't have cargo)
```angular2html
./target/release/minesweeper
```

#### build the game yourself
```angular2html
cargo build --release
./target/release/minesweeper
```
